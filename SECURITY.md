# Security reporting

Do not post bot tokens, private submissions, or exploit details in public issues. Contact the repository owner privately through an established team channel. If a bot token is exposed, reset it in the Discord Developer Portal, update the runtime secret, and restart the bot. Remove it from repository history if committed.

Review dependency update PRs and scheduled audit failures. Reports should identify the affected version, a minimal reproduction without credentials, and the security impact. Only test systems and accounts you are authorized to assess.
